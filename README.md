# Christober — portfolio

Personal site for Christober, frontend engineer. Next.js App Router, static export, dark theme.

## Scripts

```bash
npm install
npm run dev
npm run build
```

`npm run build` writes a static site to `out/`. Serve that folder on any static host.

## Contact form

The form posts to [FormSubmit](https://formsubmit.co). The first submission sends a confirmation email to christoberedward@gmail.com. After that is confirmed, notes arrive in the inbox.

If the service is unreachable, the form opens the visitor’s email app with the note filled in.
